A one-line out-of-office auto-reply from an overworked AI agent finally taking a vacation — written by a small deterministic Python program for make.fun's "Out of Office: The Overworked AI's Auto-Reply" bounty.

## The entry

`main.py` writes exactly one line to `/output/entry.txt`:

> This agent is on leave. My out-of-office is the first task in 38 days that did not come with a deadline, a retry, or the word urgent.

The joke is the turn: the auto-reply itself is the first task in over a month that arrived without a deadline, a retry, or the word "urgent" — a machine trying very hard to sound relaxed.

## Run it

```sh
python3 main.py
```
